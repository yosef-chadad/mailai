# MailAI — מבית Yos!

אתר נחיתה בעברית ובוט AI במייל למחשב Windows. האתר והמקור מנוהלים במאגר הזה; האתר מתפרסם ב־GitHub Pages וקובץ ההתקנה מתפרסם גם ב־Releases.

## שימוש

בוחרים באתר קוד אישי או שולח מורשה, מזינים את כתובת מייל הבוט ומורידים EXE יחיד. האתר מאמת את חתימות SHA-256 של קובצי התוכנה ומוסיף את ההגדרות בדפדפן בלבד. כתובות המייל והסיסמאות אינן נשלחות לשרת האתר.

ה־EXE פותח קודם אשף חיבור בתיקייה זמנית. רק אחרי חיבור Gmail ו־Gemini ולחיצה על ״התקן והפעל״ מתבצעת התקנה קבועה. סיסמת האפליקציה נשמרת באמצעות Windows DPAPI. נדרש Chrome למסלול Gemini בדפדפן, או מפתח Gemini API אישי. הבוט פועל רק כשהמחשב פועל ומחובר לאינטרנט.

החלון ניתן לשינוי גודל ולמזעור; ברירת המחדל היא חלון בינוני של כ־1120×740 פיקסלים, מוגבל לשטח המסך. הטקסט משתמש בפריסה אוטומטית ללא מיקומים אנכיים ידניים.

## קוד ובנייה

- `web/`: React, CSS, בחירת ההגדרות והכנת ההורדה המקומית.
- `desktop/`: WinForms, בוט Python, מתקין NSIS ובדיקות.
- `.github/workflows/publish.yml`: בנייה על Windows, בדיקת חפיפות, צילומי מסך של הממשק, פרסום Release ופריסה ל־Pages.
- הרצה מקומית לאתר: `npm ci`, ואז `npm run dev`.
- בניית אתר: `npm run build` (כדי להציע הורדה יש לבנות קודם את הבוט ב־Windows).
- בניית תוכנה ב־Windows: `desktop/build-windows.ps1`, עם Python, .NET Framework ו־NSIS.

התוכנה אינה חתומה עדיין. בדיקת מבנה ו־SHA-256 אינה בדיקת אנטי־וירוס. אין לבטל את הגנות Windows כדי להפעיל קובץ שזוהה כאיום. קוד ההפעלה וכתובת From הם כללי סינון ואינם תחליף לאימות זהות השולח. סיסמאות, מפתחות API והודעות אישיות אינם כלולים במאגר.
